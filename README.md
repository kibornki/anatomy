# Anatomy

상체·팔·복부·전완·허벅지 근육 애니메이션입니다.
각 부위에서 정면·후면·측면, 재생, 각도, 근섬유와 반투명 컨트롤을 제공합니다.

- 통합: `index.html`
- 가슴·등·전거근을 통합한 상체: `upperbody.html`
- 이두·삼두·삼각근을 통합한 팔: `arm.html`
- 전거근·외복사근·내복사근·복직근·광배근의 복부: `abdomen.html`
- 허벅지: `thigh.html`
- 전완: `forearm.html`
- 기존 등 주소: `back.html` → 상체 후면

상체 세 방향은 머리를 제외하고 목부터 골반까지 보여줍니다.
정면·후면 흉곽의 가로·세로와 어깨·골반 상대 비율을 교재 도판과 대조해 보정했습니다.
기존 작화 방식과 근육 색상·선 두께를 유지합니다.
척추 구간·12쌍의 늑골과 흉곽·허리·골반 기준, 어깨 운동 변환을 공유합니다.
정면은 대흉근 하부와 늑연골 연결을 조정했고, 후면은 광배근의 허리 윤곽과 골격 가림을 수정했습니다.
과도한 어깨 폭·허리 잘록함과 흉곽 대비 상완골 길이도 조정했습니다.
후면 척추뼈는 반투명 모드에서 확인합니다.
전거근은 연결된 면으로 늑골의 앞가쪽에서 견갑골의 늑골면으로 이어집니다.
정면에서도 대흉근 아래 양옆의 하부 톱니가 불투명 상태에서 드러납니다.
상부와 견갑골 쪽의 깊은 연결은 반투명으로 살펴볼 수 있습니다.
측면은 척추의 경추·흉추·요추 굴곡, 기울어진 흉곽과 열두 늑골, 골반을 기반으로 근육을 배치합니다.
기존 색상·선 스타일을 사용하며 공통 팔 외전 범위는 15–120°입니다.
팔의 정면·후면은 16°, 허벅지는 32° 비스듬한 시점으로 깊이 방향의 굽힘이 보입니다.
카메라 전환 시 각도를 유지하며, 탭·새로고침 후 부위별 상태를 복원합니다.

외부 파일이나 빌드 의존성이 없는 정적 HTML입니다. 복부는 SVG 도해를 유지하고, 카메라 깊이를 비교한 가림 경계를 적용합니다. 모바일 브라우저에서도 동작합니다.
근육 외형과 변형은 작화용 단순화이고 활성도·힘·실측 근섬유 수축률을 계산하지 않습니다.
상체는 교재 도판을 참고한 방향별 2D 도해이며, 도판 비율은 실측 인체의 정상 범위가 아닙니다. 허벅지는 OpenSim Gait2392의 근육·힘줄 경로 변화를 참조합니다.
전거근·삼각근은 OpenStax 공식 교재 본문·도판과 대조해 외형과 겹침을 수정했습니다.
팔꿈치의 활차·소두와 척골 C자 홈, 삼두 공통 힘줄과 이두근 건막을 교정했습니다.
팔·전완의 손 길이와 허벅지의 발 크기·아치를 보완했습니다.
삼각근 등 근육의 정확한 볼륨이나 개인별 비율은 실측으로 검증하지 않았습니다.
검토 근거와 한계: [ANATOMY_REVIEW.md](ANATOMY_REVIEW.md).

## 검증

정면 6개·후면 14개 근육 영역과 모든 근섬유의 원래 색상·선 두께를 네 각도에서 비교했습니다.
정면 흉곽 폭/높이 약 0.954, 골반/흉곽 폭 약 0.947과 팔 각도 보존·머리 제거를 검사했습니다.
정면·후면 24개 조합에서 늑골 연결·골격 가림·공유하는 어깨 운동·이름표의 근육 내부 도착점을 검사했습니다.
정면 전거근의 실제 표면 노출과 이름표 끝이 보이는 근육을 가리키는지도 검사했습니다.
측면의 척추 굴곡·늑골 연결 규칙과 팔을 올릴 때 몸통 골격이 고정되는 것도 검사했습니다.
삼각근 세 부분의 연결 경계, 팔·허벅지의 사선 카메라와 관절 이동을 확인했습니다.
허벅지의 긴뼈 길이·근육과 참조 길이는 유지하며 발과 아킬레스건 부착을 교정했습니다.
Chromium에서 재생·일시정지·상태 복원, 모바일 320/390/680px 조작부를 검사하고
기존 네 부위의 세 시점을 데스크톱·모바일 캡처로 확인했습니다.
팔 136개·허벅지 121개 각도에서 관절·손·발의 강체 연결과 그림 영역 경계를 검사했습니다.
전완 손의 강체 회전과 척골 고정, 세 부위의 72개 시점·각도·투명 상태도 검사했습니다.

## 복부

정면 16° 사선과 측면의 C자 말기에 **비틀기**를 추가했습니다. 측면 옆의 비틀기 버튼에서 전환합니다.
골반과 카메라는 고정하고 흉곽·견갑대·척추와 복벽을 회전합니다. 앞뒤 표면의 실제 깊이로 뼈와 근육의 가림을 결정합니다.
광배근은 뒤쪽의 연결된 부채꼴로 넓은 하부 기시에서 뒤겨드랑이 쪽으로 모이며, 회전하면 드러나는 면이 바뀝니다.
전거근·외복사근·내복사근·복직근과 기존 근섬유·반투명 조작부를 함께 제공합니다. 가려진 근육의 이름표는 숨깁니다.

말기 0–100%와 비틀기 −60°부터 +60°는 별도로 저장합니다. 이전 복부 저장값을 이어 쓰며, 새 사용자 기본 화면은 정면·폄·일시정지입니다.
비틀기 숫자는 도해의 상부 회전값이고 인체 추간관절의 정상 가동범위나 실제 근섬유 수축률이 아닙니다. 최대 자세는 승인한 시안의 작화용 표현입니다.
정면의 팔뼈를 생략하는 기존 구조와 UI를 유지합니다.

생성: `python work/abdomen/build.py --publish`.
검증: `python work/abdomen/review.py` (로컬 서버 기본 주소 `http://127.0.0.1:8767/`).
자세·깊이 가림·골반 고정·뼈 길이·광배근 연결·이름표 적중·저장값 이관·샌드박스·모바일 터치를 확인합니다.
소스와 한계: [work/abdomen/README.md](work/abdomen/README.md).

## 팔

현재 팔은 복부와 같은 BodyParts3D 오른팔 아틀라스의 뼈·근육 외곽을 사용합니다.
삼두 후면에 넓은 건막과 그 양옆으로 모이는 사선 근섬유를 추가했습니다.
이두 장두·단두는 빨강·파랑, 삼두 장두·외측두·내측두는 빨강·파랑·초록입니다.
건막·섬유는 승인한 참고 이미지에 따른 작화용 근사이며 측정된 조직 분할이 아닙니다.
기존 정면·후면·측면, 재생·각도·근섬유·반투명 UI와 저장된 상태를 유지합니다.

생성: `python work/arm/build.py --publish`.
검증: `python work/arm/review.py` (로컬 서버 기본 주소 `http://127.0.0.1:8767/`).
24개 시점·굽힘·투명도 조합의 뼈 강체 회전, 고정된 어깨, 라벨 적중,
근두 색상, 재생·저장값·모바일 조작과 통합본의 팔 문서만 바뀌는 것을 검사합니다.
소스와 한계: [work/arm/README.md](work/arm/README.md).
