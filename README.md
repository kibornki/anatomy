# Anatomy

상체·팔·전완·허벅지 근육 애니메이션입니다.
각 부위에서 정면·후면·측면, 재생, 각도, 근섬유와 반투명 컨트롤을 제공합니다.

- 통합: `index.html`
- 가슴·등·전거근을 통합한 상체: `upperbody.html`
- 이두·삼두·삼각근을 통합한 팔: `arm.html`
- 허벅지: `thigh.html`
- 전완: `forearm.html`
- 기존 등 주소: `back.html` → 상체 후면

상체 정면·후면은 통합 전 가슴·등의 원본 SVG 곡선·근섬유·색상을 유지합니다.
전거근은 연결된 면으로 늑골의 앞가쪽에서 견갑골의 늑골면으로 이어집니다.
정면에서는 대흉근 아래의 깊은층이며 반투명으로 살펴볼 수 있습니다.
같은 스타일의 측면을 제공하고 공통 팔 외전 범위는 15–120°입니다.
팔·허벅지의 정면·후면은 32° 비스듬한 시점으로 깊이 방향의 굽힘이 보입니다.
카메라 전환 시 각도를 유지하며, 탭·새로고침 후 부위별 상태를 복원합니다.

외부 파일이나 빌드 의존성이 없는 정적 HTML입니다. 모바일 브라우저에서도 동작합니다.
근육 외형과 변형은 작화용 단순화이고 활성도·힘·실측 근섬유 수축률을 계산하지 않습니다.
상체는 방향별 2D 도해입니다. 허벅지는 OpenSim Gait2392의 근육·힘줄 경로 변화를 참조합니다.
전거근·삼각근은 OpenStax 공식 교재 본문·도판과 대조해 외형과 겹침을 수정했습니다.
삼각근의 정확한 볼륨이나 개인별 비율은 실측으로 검증하지 않았습니다.
검토 근거와 한계: [ANATOMY_REVIEW.md](ANATOMY_REVIEW.md).

## 검증

원본 가슴 6개/등 14개 영역의 실제 SVG 곡선·근섬유·색상을 네 각도에서 비교했습니다.
삼각근 세 부분의 연결 경계, 팔·허벅지의 사선 카메라와 관절 이동을 확인했습니다.
허벅지의 뼈·근육·힘줄과 참조 길이는 직전 배포 소스의 75개 자세와 동일합니다.
Chromium에서 재생·일시정지·상태 복원, 모바일 320/390/680px 조작부를 검사하고
네 부위의 세 시점을 데스크톱·모바일 캡처로 확인했습니다.
