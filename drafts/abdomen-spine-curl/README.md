# 복부 — 승인된 상체 척추 C자 말기

승인된 시안의 상체 척추 C자 말기를 통합본과 독립 복부 페이지에 적용한다.

- 기존 상체의 골격 소스와 복부의 전거근·외복사근·내복사근·복직근 윤곽 및 섬유를 재사용한다.
- 추가했던 다리와 고관절 굽힘, 골반 회전을 제거했다. 골반과 카메라는 폄/말기 사이에 고정된다.
- 흉추부터 요추까지 분산해서 굽힌다. 흉곽 전체를 허리의 단일 축에서 회전시키는 방식은 사용하지 않는다. 각 척추뼈는 해당 위치의 기울기를 따라 움직이며 크기를 유지한다.
- 각 늑골은 해당 흉추 Ti를 기준으로 움직인다. 늑골 조각의 길이를 유지하면서 복벽과 근섬유는 둥근 몸통 곡선을 따른다.
- 슬라이더 0–100%는 시안의 폄/말기 진행 정도다. 실제 관절의 최대 가동범위나 근육 수축률을 나타내지 않는다. 최대 말기에서 위쪽 척추의 도해 기울기는 80°이며, 아래쪽에서 위쪽으로 점차 증가한다.
- 기존 선, 색상, UI와 정면 16°·측면 시점을 유지한다. 반투명 화면에서 척추 굴곡을 확인할 수 있다.
- 정면에서는 사용자가 요청한 대로 팔뼈를 생략하고 쇄골·견갑골을 유지한다.

## 생성과 확인

저장소 루트에서 `python drafts/abdomen-spine-curl/build.py`를 실행하면 독립적인 `drafts/abdomen-spine-curl.html`을 만든다. `--publish`를 추가하면 `abdomen.html`과 통합본의 복부 문서도 갱신한다. 다른 부위와 통합 UI는 유지한다.

로컬 서버가 저장소 루트를 제공할 때 `python drafts/abdomen-spine-curl/review.py`로 확인한다. 기본 주소는 `http://127.0.0.1:8766/abdomen.html`이다.

검증: 정면·측면 각 다섯 자세, 네 근육명 선의 화면 적중, 척추뼈·늑골 조각 크기 유지, 늑골의 올바른 흉추 연결, 골반과 카메라 고정, 다리 요소 부재, 재생·정지, 모바일 320/390/680px. 폄·중간·말기 및 반투명 화면을 별도로 육안 확인한다. 자세 도해를 검토하는 검사이며 해부학적·임상적 정확성의 인증은 아니다.

근육 층과 섬유 방향의 자료 기준은 OpenStax Anatomy & Physiology 2e 11.4 및 11.5, 골격의 기준은 기존 상체 시안과 동일하다. 사용자가 첨부한 이미지는 근육 흐름 참고용이며 추적하거나 재배포하지 않았다.

통합 검사: `python drafts/abdomen-spine-curl/review-hub.py`. 기본 주소는 `http://127.0.0.1:8767/`이며 `ANATOMY_HUB_URL`로 바꿀 수 있다. 독립 검사 주소는 `ANATOMY_REVIEW_URL`로 바꿀 수 있다.
