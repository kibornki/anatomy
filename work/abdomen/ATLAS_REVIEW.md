# 2026-10-09: 공통 3D 아틀라스로 복부 재구성

이 문서는 이전 v3의 수작업 곡면 검토를 대체한다. `classic-*.js`, `flexion.js`, `muscle-surfaces.js`와 기존 OpenStax 검토 기록은 과거 구현이며 현재 빌드에 포함하지 않는다.

## 실제 읽고 사용한 자료

**DBCLS BodyParts3D / Anatomography 3.0**의 배포 README, 좌표계, 부위 목록, STL 표면 데이터. [공개 변환본](https://github.com/Kevin-Mattheus-Moerman/BodyParts3D/tree/f0eeb6e843380cfe6b83797cf8c3e1af74de5e61), 고정 커밋 `f0eeb6e843380cfe6b83797cf8c3e1af74de5e61`. Kevin Mattheus Moerman이 DBCLS OBJ를 STL로 변환한 자료다. 인용: Mitsuhashi N et al., *BodyParts3D: 3D structure database for anatomical concepts*, Nucleic Acids Research 37:D782–D785 (2009), DOI `10.1093/nar/gkn613`. 이번에 논문 원문을 열람했다는 의미는 아니다.

**Stanford/OpenSim의 [ScapulothoracicJointPlugin](https://github.com/opensim-org/ScapulothoracicJointPlugin/tree/ad2a40c0fdb242eb8de9b61c56aae9418303225b)**, 저자 Ajay Seth. 공식 헤더·구현에서 흉곽 표면을 따라 견갑골 위치를 다루는 원칙을 확인했다. 이 플러그인 전체를 앱에 이식한 것은 아니다. 앱은 원본 늑골 접촉 기준을 사용하는 자체 작화용 구속을 구현한다. 이 자료는 60° 몸통 비틀기나 조직 변형을 검증하는 동작 데이터가 아니다.

NCBI, UW, TeachMeAnatomy는 현재 환경에서 차단되어 열람하지 못했다. 이들 자료를 구현 근거로 인용하지 않는다. 생성 이미지도 근거로 사용하지 않는다.

## 데이터와 구현

- C7, T1–T12, L1–L5, 늑골 1–12, 늑연골 1–7, 흉골 세 부분, 견갑골, 쇄골, 장골과 천골을 동일 좌표계에서 가져왔다. 머리·상완골은 제외한다.
- 전거근 FMA13399, 외복사근 FMA13337, 광배근 FMA13359, 복직근 FMA13378, 내복사근 FMA13893. 대흉근의 쇄골·흉골·복부 부분은 회색 문맥으로 표시한다.
- 원본 mm 좌표에 **동일한 0.58 배율**과 좌표축 변환만 적용한다. 좌우·상하를 각각 늘이지 않는다. 좌측 뼈와 근육을 우측에 반사했다. 단일 아틀라스의 대칭 도해로, 일반 인구의 표준 비례나 실제 비대칭을 나타내지는 않는다.
- 각 원본 STL의 SHA-256, 원래/축소 삼각형 수, 원래 좌표 범위와 축소 후 범위 오차는 `atlas-data.json`의 각 `audit`에 포함한다. 표면 축소는 quadric decimation이다. 이것은 모든 지점의 Hausdorff 오차 검증이 아니다.
- 정면 16°, 측면 90°, 비틀기 16° 카메라가 **동일한 3D 표면**을 투영한다. 서로 다른 정면·측면 뼈 도형에 깊이를 덧붙이지 않는다.
- 전거근 갈래의 표시 기준은 해당 늑골 표면과 견갑골 안쪽 모서리이다. 아래 갈래는 실제 견갑골 아래각 방향으로 이어진다. 원본 전거근·외복사근의 맞물리는 외형을 사용하며 한 근육으로 융합하지 않는다.
- 복직근 노출과 내복사근 절개창을 위해 외복사근의 일부를 원래 삼각형 위에서 절개한다. 근복/흰 건막 색상 경계, 절개창, 건획 세 줄은 **작화 표기**다. 아틀라스에 실측 분류·근섬유 궤적·건획 지도가 들어 있다는 뜻이 아니다. 반사된 중앙 분할 틈에는 원본 건막의 깊이를 따른 좁은 백선을 표시한다.
- 섬유는 부착 영역 간의 원통 좌표 가이드를 실제 근육 표면의 바깥 면에 투영한다. 수직 sine 굴곡으로 부채꼴을 만들지 않는다. 섬유 방향은 해부학 관계를 설명하는 근사이며 실측 tractography가 아니다.
- 척추의 원래 시상 곡선을 적분하여 C자 말기를 만든다. 골반은 고정하고 뼈는 강체로 유지한다. 피부·근육은 가까운 뼈와 연속 척추장 사이에서 dual quaternion skinning으로 움직인다. 뼈 가까이에서는 해당 뼈를 정확히 따른다.
- 늑연골은 해당 늑골과 흉골에 전체 길이가 연결되도록 변형한다. 복직근 위쪽과 앞쪽 건막은 가까운 늑연골의 동일한 변형 기준을 공유한다. 원본 복직근의 늑연골 접촉 구간에서 치골 쪽까지 공통 앞 복벽장으로 회전을 나눠, 근육과 주변 건막이 서로 갈라지지 않게 한다. 늑골 끝의 앞쪽 높이를 척추의 같은 높이로 잘못 취급하던 문제를 수정했다.
- 견갑골은 여러 늑골 기준의 평균 강체 프레임을 따르며, 원래 견갑–늑골 방향 간격이 줄어드는 접촉 기준에서는 위치를 보정한다. 근육 전체를 가상의 타원 흉곽 밖으로 밀어내는 이전 보정은 제거했다. 이 구속도 모든 관절 접촉·압력·winging을 재현하는 생체역학 해석은 아니다.
- 비틀기 ±60°에서 요추 5°/흉추 55°, 말기 최댓값에서 각각 30°를 분배한다. **작화용 운동 설정이며 정상 가동범위나 생리학적으로 검증된 조직 변형이라고 주장하지 않는다.**

## 확인 범위

`review.py`는 15개 자세에서 골반 고정, 강체 뼈 길이, 유한 좌표, 중립 자세의 방향별 3D 일치, 깊이 가림, 조작, 반투명, 모바일 390/320px와 통합 상태 복원을 검사한다. `geometry-audit.py`는 표시하는 근육 면의 정점과 실제로 움직인 늑골 사이의 ray-parity 후보 및 가장 가까운 삼각형 거리를 기록한다. 복직근을 노출하려고 제거한 외복사근 건막 면은 표시 면 검사에 포함하지 않는다. 아틀라스 자체의 작은 접촉 겹침도 남겨 기록한다. 이 검사는 모든 삼각형 교차나 조직 미끄러짐·체적·수축률을 완전히 검증하지 않는다.

원본 기준, 양 끝 비틀기, 최대로 말린 측면, 반투명, 모바일과 통합 화면을 직접 비교하여 메쉬 내부 면 경계가 불필요한 검은 선으로 보이는 문제와 안쪽 표면의 섬유 겹침을 수정했다. 재검토 중 발견한 끝 각도의 전거근–늑골 접촉 변화는 견갑 접촉 구속으로 개선했다.

### 최종 검사 기록

[atlas-validation.json](atlas-validation.json)에 원본 데이터 해시, 15개 자세, 조작 검사와 실제 표시 정점의 접촉 비교를 보관했다. 전거근·외복사근·광배근의 원본 접촉 후보는 각각 6·16·2개이고, 원본 및 전 자세의 최대 표면 거리는 각각 0.5549·0.2731·0.0785 도해 단위였다. 복직근과 표시 내복사근에는 해당 늑골 내부 후보 정점이 없었다. 이 결과는 이 축소 메쉬의 표시 정점 검사이며 모든 면 교차나 생리학적 변형을 인증하지 않는다.
