# 전거근·외복사근 형태와 비틀기 수정

사용자가 제공한 측면 해부 도판과 OpenStax 11.12의 갈래·섬유 관계를 다시 대조했다. 기존의 부착점과 접촉 경계 검사 통과를 근육 외형의 정확성으로 해석하지 않는다.

- 상부 전거근은 늑골 사이에 골이 있는 둥근 갈래로 표현한다. 하부 갈래는 외복사근의 상부 갈래와 같은 접촉 경계를 사용한다. 두 근육의 섬유는 연결하지 않는다.
- 맞물림 경계의 늑골 사이 골은 뒤쪽으로 들어간다. 이전 경계는 반대쪽으로 돌출되어 갈래가 큰 판처럼 보였다.
- 측면 외복사근 근복을 앞쪽 건막까지 넓힌다. 상부 측면 섬유는 아래·앞으로 흐르고, 뒤쪽 아래 섬유는 장골능으로 내려간다.
- 갈래별 섬유 묶음과 경계의 약한 명암을 기존 SVG 색상·뼈 표현에 추가한다. UI와 시점은 유지한다.

소스에서 `drafts/abdomen-twist-reviewed.html`, 독립 문서 `abdomen.html`, 통합본 `index.html`의 복부 문서를 생성한다. 다른 부위 문서는 유지한다. 초기 확대 비교 캡처에서는 전거근·외복사근을 읽기 위해 다른 근육을 일시적으로 생략했으나, 실제 게시 문서에는 다섯 근육과 가슴 문맥을 모두 유지한다.

초기 정지 시안의 -60° 검사는 전거근 섬유 길이 비율 1.979로 기존 상한 1.8을 초과했다. 다음 원인을 수정했다.

- 부착 보정에 각 내부 점을 다시 회전시키던 오류를 제거하고 실제 기시·정지의 이동 차이를 사용한다. 비틀기의 내부 회전은 양쪽 부착의 회전을 각도로 연결해 흉곽을 가로지르는 직선 보간을 피한다.
- 흉추 회전 분포의 상·하 접점을 부드럽게 하고 중간 흉곽과 견갑대의 상대 회전 차이를 줄인다. 최대 상부 60°·요추 5° 설정은 유지하며 임상 가동범위라고 주장하지 않는다.
- 전면 건막과 복직근의 위쪽은 흉골·늑연골 부착을 따르고 아래쪽은 장골·치골에 고정한다. 외복사근의 앞쪽 정지도 같은 건막 움직임을 따른다. 척추와 같은 높이라는 이유로 앞 복벽에 척추 회전값을 그대로 적용하지 않는다.
- 가림용 외피 중심은 변하는 늑골 볼록껍질 꼭짓점 수 대신 몸통 표면에서 구한다. 바깥쪽 최대값 필터 후 양의 평활 필터를 적용해 외피가 개별 늑골 윤곽을 근섬유에 새기는 현상을 줄인다.

수정 후 23자세 검사를 통과했다. 최대 섬유 길이 비율은 1.755이며 기존 상한을 완화하지 않았다. 전거근·외복사근 접촉 경계 차이는 1.2e-13 도해 단위 이하, 전면 외복사근 상부 정지와 실제 렌더된 건막 경계 차이는 1e-8 미만이다. 뼈·늑연골 연결, 반투명, 이름표, 상태 복원·재생, 모바일·터치 검사도 통과했다. 화면의 ±60° 섬유 흐름을 대조했다. 이 수치는 작화의 안정성 검사이며 실제 생리적 근섬유 신장률이나 조직 접촉 검증이 아니다.

정면·측면의 중립 및 최대 말기, ±60° 비틀기·반투명·모바일 캡처와 `verification.json`은 `/workspace/artifacts/abdomen-fascicle-review/`에 있다. 초기 `side-muscle-detail.png`는 비교용 층 생략을 적용한 시안으로, 최종 게시 화면은 전체 캡처를 참조한다. 생성 이미지가 아니라 실제 SVG 화면이다.

## 하부 전거근 부채꼴 — 승인 시안 반영

사용자가 승인한 생성 이미지는 섬유 흐름의 시각적 가이드로 사용한다. 해부학 근거는 사용자 해부 도판과 기존 교재 참조이며, 생성 이미지의 뼈 모양·비율을 복사하지 않는다.

하부 늑골 기시 범위와 견갑골 정지 범위를 비슷한 높이로 배치한 기존 도해는 거의 평행한 수평 띠처럼 보였다. 정면·비틀기의 여덟 번째 늑골 기시가 지나치게 뒤쪽에 놓여 하부 기시 높이 범위를 좁혔다.

- 하부 기시를 앞가쪽 늑골 면에 배치한다. 앞·측면 모두 하부 기시 높이 범위는 약 40 도해 단위이다.
- 상부·중부 전거근은 안쪽 모서리 정지를 유지하고, 하부 갈래 정지는 견갑골 아래각 주변 약 8 도해 단위의 범위로 모은다. 실제 견갑골 곡선과 부착 관계는 기존 검사를 유지한다.
- 하부 갈래는 뒤로 감싸는 동안 위쪽으로 휘어, 광배근 뒤에 가려지기 전 노출된 옆구리에서도 부채꼴 흐름을 보인다. 섬유·갈래 경계·근복 면은 같은 곡면을 사용한다.
- 근복 가장자리로 제한된 섬유선이 중복 그려져 좁은 정지 쪽을 검게 만들던 문제를 제거한다. 기존 색상·선 스타일·골격·UI·시점·60° 범위는 유지한다.

검사에는 하부 기시의 높이 순서와 넓은 기시/좁은 정지 관계, ±60° 실제 투영에서 노출된 하부 섬유의 방향 차이, 중복 섬유선을 추가한다. 투영 방향 차이 기준은 시각적 흐름을 확인하는 작화 기준이며 임상 섬유 각도가 아니다. 접촉 경계·근육 외피 여유·실제 늑골/견갑골 부착·건막 연결·뼈 크기·투명도·모바일 조작 검사는 유지한다.

최근 캡처와 `verification.json`은 `/workspace/artifacts/serratus-fan-review/`에 저장한다. `twist-60-after-body.png`와 `twist-60-mobile.png`는 실제 SVG 렌더이며, 초기 생성 시안과 구분한다.


## 교재 부착 기준 재검토 — 과장된 수렴 제거

앞 절의 승인 시안 반영은 이전 구현의 기록이다. 아래 내용이 현재 구현 기준이다. 생성 이미지는 형태의 정확성을 판단하는 근거로 사용하지 않았다.

실제로 대조한 자료:

- [OpenStax 11.5 본문·표](https://github.com/openstax/osbooks-anatomy-physiology/blob/5ae32b3f4bc24ed003e91dc38bf47dba80751044/modules/m46495/index.cnxml): 전거근 기시는 “Muscle slips from certain ribs (1–8 or 1–9)”, 정지는 “Anterior surface of vertebral border of scapula”. 전거근은 늑골 바깥을 감싸 견갑골의 늑골면 안쪽 모서리에 붙는다.
- [OpenStax 그림 11.18](https://github.com/openstax/osbooks-anatomy-physiology/blob/5ae32b3f4bc24ed003e91dc38bf47dba80751044/media/1118_Muscles_that_Position_the_Pectoral_Girdle.jpg): 가슴·삼각근이 절제된 전거근 도판. 흉곽을 감싸는 넓은 갈래와 견갑골 아래쪽을 향하는 흐름을 직접 비교했다.
- [OpenStax 그림 11.12](https://github.com/openstax/osbooks-anatomy-physiology/blob/5ae32b3f4bc24ed003e91dc38bf47dba80751044/media/1112_Muscles_of_the_Abdomen.jpg) 및 [11.4 본문](https://github.com/openstax/osbooks-anatomy-physiology/blob/5ae32b3f4bc24ed003e91dc38bf47dba80751044/modules/m46485/index.cnxml): 전거근과 외복사근의 맞물림, 외복사근의 아래·안쪽 섬유 방향과 앞쪽 건막. 맞물림은 별개 근육의 갈래 사이 관계이며 서로의 섬유를 융합하지 않는다.

이전 구현에서 전거근 아래 갈래를 위로 5–10 도해 단위 휘게 하는 항과 과도하게 좁은 정지 범위를 함께 넣었다. 화면의 부채꼴을 강조하기 위한 선택이었으며 교재에서 얻은 수치가 아니었다. 이번에는 이 수직 굴곡 항을 제거하고, 기존 견갑골 아래쪽 모서리의 유한한 범위에 정지를 분산했다. 부착점의 높이 차이와 흉곽을 감싸는 곡면에서 섬유 방향이 나오도록 한다. 갈래 사이 깊은 홈도 줄였다. 정확한 분산 비율·홈 깊이는 여전히 도해의 작화 값이다.

확대 렌더 재검토에서 상부 전거근이 늑골 기시 직후 부풀어 보이는 별도 원인을 발견했다. 상부 흉곽 외피를 어깨 너비의 별도 타원으로 구성하고 있었다. 그 너비를 실제 도해 늑골의 높이·최대 폭에서 생성하도록 변경했다. 늑골 좌표와 근육의 기준 면에 서로 다른 너비를 사용하는 문제를 줄인다. 원래 골격과 카메라, 색상·선 스타일, 조작 UI는 유지한다.

검사 기준도 구분했다. 이전의 정지/기시 높이 범위 비율 0.3 미만, 보이는 측면의 섬유각 차이 25° 초과는 해부학 근거가 없는 작화 목표였다. 전자는 넓은 기시보다 좁되 0이 아닌 정지 범위라는 구조 검사로 변경했고, 후자는 시각 검토용 기록으로 남겼다. 실제 렌더된 늑골·견갑골과의 부착, 공유 경계의 틈, 흉곽 관통, 섬유 길이 안정성 검사에는 기존 허용치를 그대로 적용했다.

최종 검사와 캡처: `/workspace/artifacts/serratus-attachment-review/`. 정면·측면의 말기 0/25/50/75/100과 비틀기 -60°부터 60°까지의 23개 자세, 불투명/반투명, 상태 복원·재생, 모바일·터치와 통합본을 확인한다. `*-after-body.png`는 실제 앱의 확대 렌더이며 생성 시안이 아니다. `*-before-body.png`와 `before-after-geometry.json`도 함께 기록했다. 전체 근섬유의 국소 굴곡 수치가 모두 감소한 것은 아니므로, 수치 하나를 형태 개선의 증명으로 사용하지 않는다.

부착·가림 검사와 도판 비교는 서로 다른 검토다. 이번 변경은 잘못 추가한 형태 과장을 바로잡지만, 두 방향의 골격 도해를 사용하는 모델을 실측 3D 해부 표본이나 생리적 근육 변형 모델로 바꾸지는 않는다. 60° 비틀기와 정확한 갈래 폭은 교재에서 측정한 정상값이 아니다.
