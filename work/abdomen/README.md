# 복부 말기·비틀기

복부 정면·측면·비틀기가 같은 곡선 도해와 근섬유를 사용한다. 기존 상체의 뼈·선 스타일을 유지하고, 골반과 카메라를 고정한다.

- `muscle-surfaces.js`: 전거근·외복사근·광배근의 기시·정지와 곡면, 늑골별 기시 추종·견갑대 정지 추종·장골능 고정. 양 시점은 각 골격의 부착 좌표를 사용한다.
- `flexion.js`: 연결된 근육 윤곽, 섬유, 건막, 내복사근 절개창, 늑골·흉골·견갑대. 개별 뼈는 강체로 움직이고 연골은 부착점 사이를 연결한다. 말기와 비틀기를 3D 좌표에 적용한 뒤 SVG로 투영한다.
- `twist.js`: 동일한 도해의 척추 축 회전. 별도의 각진 메쉬나 깊이 버퍼를 사용하지 않는다.
- `style.css`: 반투명 시 각 근육의 면·섬유·건획을 하나의 그룹으로 옅게 표시한다. 뼈에는 투명도를 적용하지 않는다. 해부학 도해의 겹침 순서로 층을 표현한다.
- `controls.js`: 말기/비틀기의 독립 값, 재생·정지, 모바일 맞춤, 통합 상태 저장. 이전 두 버전의 저장값을 이관하고 과한 비틀기는 제한한다.
- `build.py`: 외부 자산 없이 HTML 생성. `--publish`는 독립 페이지와 통합본의 복부 문서만 갱신한다.
- `review.py`: 회전 분포·뼈 크기·연골 연결·섬유 변형·실제 투명도·저장값·모바일·터치 검사와 화면 캡처.

저장소 루트에서 `python work/abdomen/build.py --publish`로 생성한다. 루트를 제공하는 로컬 서버에서 `python work/abdomen/review.py`로 검사한다. 기본 주소는 `http://127.0.0.1:8767/`, `ANATOMY_REVIEW_BASE`로 변경 가능하다.

전거근은 1–8번 늑골에서 견갑골 늑골면 안쪽 모서리로, 외복사근은 5–12번 늑골에서 앞쪽 건막·장골능으로, 광배근은 하부 흉추·흉요근막·장골능에서 상완골 근위부를 생략한 뒤겨드랑이로 연결한다. 각 근육의 면과 섬유는 동일한 부착 좌표를 공유한다. 늑골 기시는 개별 늑골의 움직임을 따르고, 장골능 기시는 골반과 함께 고정한다.

외복사근은 넓은 옆구리 근복과 앞쪽 건막을 구분한다. 전거근과 겹치는 톱니는 각 늑골에서 시작한다. 가슴 문맥은 아래쪽 흉골·늑연골 기시까지 확장한 부채꼴이다. 뒤쪽 면과 섬유는 현재 카메라를 향하는 부분만 불투명으로 그린다. 반투명에서는 전체 면을 한 근육 그룹으로 옅게 표시한다. 몸통의 폭·깊이는 매끄럽게 보간해 중간에 폭이 갑자기 줄어들어 섬유가 꺾이는 오류를 없앴다.

검사는 실제 늑골 도해와 근육 기시의 거리, 장골능 고정, 겨드랑이 끝의 추종을 포함한다. 좌표·동작 검사가 해부학 전체의 정확성을 보증하지 않으므로 도판과 렌더 화면을 직접 대조한다.

새 사용자 기본 자세는 정면·폄·일시정지다. 최대 비틀기는 ±60°, 도해에서 요추 5°와 흉추 55°에 나누어 적용한다. 최대 말기는 요추 30°와 흉추 30°로 분산한다. **이 수치는 작화용 설정이며 자료가 규정한 정상 가동범위가 아니다.** 임상적 한계, 실제 늑골 관절, 복압, 섬유 수축률을 계산하지 않는다. 흉곽의 여러 뼈를 도해의 관절 틀로 연결하는 근사다.

자료와 판단 근거는 `anatomy-reference-audit.json`, 저장소의 `ANATOMY_REVIEW.md`에 기록한다. 생성한 정적 시안은 해부학 근거로 사용하지 않는다.
