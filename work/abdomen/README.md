# 복부 말기·비틀기

기존 SVG 골격·색상·근섬유 스타일과 UI를 사용한다. 골반과 카메라는 고정하며, 정면은 16° 사선이다. 비틀기는 정면의 같은 면을 회전한다. 측면은 기존 측면 골격의 좌표를 사용하는 방향별 도해이며, 정면과 같은 근육 부착 위상·경계·곡면 규칙을 적용한다. 두 골격 도해를 완전한 단일 3D 표본으로 변환한 것은 아니다.

- `muscle-surfaces.js`: 늑골·견갑골·장골능·겨드랑이 기준의 부착과 곡면. 전거근과 외복사근은 5–8번 늑골의 맞물리는 경계를 공유한다. 이 경계는 별개 근육의 접촉이며 섬유를 융합하지 않는다. 근육 면은 흉곽 바깥을 감싸고, 움직인 뒤의 내부 면도 흉곽 외피 바깥으로 보정한다. 부착 끝부분에는 얇은 전이 구간을 둔다.
- `visibility.js`: 움직인 늑골·연골·흉골과 몸통 곡면에서 단면 외피를 구성한다. 불투명 화면에서는 근육 면·뼈·가슴 문맥의 카메라 깊이를 표본마다 비교해 SVG 가림 경계를 만든다. SVG를 뒤에 그렸다는 이유만으로 광배근이 앞쪽 늑골을 덮지 않는다.
- `flexion.js`: 기존 늑골·흉골·견갑대, 건막, 복직근, 내복사근 절개창과 공통 근육 면을 배치하고 움직인다. 비틀기의 앞 복벽은 위쪽 늑연골·흉골 부착에서 고정된 장골·치골로 이어지는 변형을 사용한다. 측면 견갑골은 전거근보다 바깥 층에 있다. 외복사근의 건막은 근복의 연속 부분이므로 자체 근복에 구멍을 내는 앞쪽 가림으로 취급하지 않는다.
- `style.css`: 반투명에서는 깊이 가림을 해제하고 근육 면·섬유·건획에 그룹 투명도를 한 번 적용한다. 뼈의 투명도는 유지한다.
- `controls.js`: 말기/비틀기 값, 재생·정지, 모바일 맞춤, 통합 상태 저장과 이전 저장값 이관.
- `build.py`: 외부 자산 없이 HTML 생성. `--publish`는 독립 페이지와 통합본의 복부 문서만 갱신한다.
- `review.py`: 23개 자세에서 공유 경계의 틈, 변형 후 흉곽 외피 여유, 깊이 가림, 부착, 뼈 크기·연골 연결, 섬유 안정성, 이름표, 반투명, 복원·재생과 모바일·터치를 검사한다. `AbdominalVisibility`의 별도 겹침 사례는 그리는 순서를 뒤집어도 앞쪽 뼈가 뒤쪽 근육을 가리는지 확인한다. 원래의 부착점 검사만으로 놓쳤던 전체 면·경계·가림을 구분해 검사한다.

생성: 저장소 루트에서 `python work/abdomen/build.py --publish`.
검사: 로컬 서버에서 `python work/abdomen/review.py`. 기본 주소는 `http://127.0.0.1:8767/`, `ANATOMY_REVIEW_BASE`로 변경한다. 캡처와 검사 수치는 `/workspace/artifacts/abdomen-fascicle-review/`에 저장한다. 갈래와 비틀기의 최근 수정 내역은 [FASCICLE_REVIEW.md](FASCICLE_REVIEW.md)에 있다.

전거근은 늑골에서 견갑골의 늑골면 안쪽 모서리로, 외복사근은 5–12번 늑골에서 앞쪽 건막·장골능으로 이어진다. 전거근의 아래 갈래와 외복사근의 위 갈래는 앞가쪽 흉곽에서 맞물린다. 측면 외복사근의 아래 늑골 기시는 더 뒤쪽에 위치하며, 뒤쪽 섬유는 장골능 방향으로 내려간다. 광배근은 하부 흉추·흉요근막·장골능의 넓은 면에서 뒤겨드랑이로 모이고 뒤쪽 전거근과 외복사근 일부를 덮는다. 팔뼈와 실제 상완골 정지 자체는 생략되어 있다.

최대 비틀기는 ±60°이며 도해에서는 요추 5°와 흉추 55°로 분산한다. 말기는 각각 30°로 분산한다. **작화용 설정이며 교재가 규정한 정상 가동범위가 아니다.** 단면 외피와 깊이 가림 검사는 이 도해의 관통·가림 오류를 제한하는 검사다. 실측 근육 체적, 조직 미끄러짐, 임상적 관절 접촉·압력·수축률을 검증하지 않는다.

근거는 OpenStax 그림 11.12, 11.18, 11.19와 본문이다. 참조 기록은 `anatomy-reference-audit.json`, 검토 내역은 저장소의 `ANATOMY_REVIEW.md`에 있다. 생성한 시안은 해부학적 근거로 사용하지 않는다.
