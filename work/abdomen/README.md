# 복부 말기·비틀기

복부 정면·측면·비틀기가 같은 곡선 도해와 근섬유를 사용한다. 기존 상체의 뼈·선 스타일을 유지하고, 골반과 카메라를 고정한다.

- `flexion.js`: 연결된 근육 윤곽, 섬유, 건막, 내복사근 절개창, 늑골·흉골·견갑대. 개별 뼈는 강체로 움직이고 연골은 부착점 사이를 연결한다. 말기와 비틀기를 3D 좌표에 적용한 뒤 SVG로 투영한다.
- `twist.js`: 동일한 도해의 척추 축 회전. 별도의 각진 메쉬나 깊이 버퍼를 사용하지 않는다.
- `style.css`: 반투명 시 각 근육의 면·섬유·건획을 하나의 그룹으로 옅게 표시한다. 뼈에는 투명도를 적용하지 않는다. 해부학 도해의 겹침 순서로 층을 표현한다.
- `controls.js`: 말기/비틀기의 독립 값, 재생·정지, 모바일 맞춤, 통합 상태 저장. 이전 두 버전의 저장값을 이관하고 과한 비틀기는 제한한다.
- `build.py`: 외부 자산 없이 HTML 생성. `--publish`는 독립 페이지와 통합본의 복부 문서만 갱신한다.
- `review.py`: 회전 분포·뼈 크기·연골 연결·섬유 변형·실제 투명도·저장값·모바일·터치 검사와 화면 캡처.

저장소 루트에서 `python work/abdomen/build.py --publish`로 생성한다. 루트를 제공하는 로컬 서버에서 `python work/abdomen/review.py`로 검사한다. 기본 주소는 `http://127.0.0.1:8767/`, `ANATOMY_REVIEW_BASE`로 변경 가능하다.

새 사용자 기본 자세는 정면·폄·일시정지다. 최대 비틀기는 ±40°, 도해에서 요추 5°와 흉추 35°에 나누어 적용한다. 최대 말기는 요추 30°와 흉추 30°로 분산한다. **이 수치는 보수적인 작화용 설정이며 자료가 규정한 정상 가동범위가 아니다.** 임상적 한계, 실제 늑골 관절, 복압, 섬유 수축률을 계산하지 않는다. 흉곽의 여러 뼈를 도해의 관절 틀로 연결하는 근사다.

자료와 판단 근거는 `anatomy-reference-audit.json`, 저장소의 `ANATOMY_REVIEW.md`에 기록한다. 생성한 정적 시안은 해부학 근거로 사용하지 않는다.
