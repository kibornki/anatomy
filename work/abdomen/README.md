# 복부 말기·광배근·비틀기

통합본과 독립 복부 페이지의 생성 소스다. 정면·측면의 기존 SVG C자 말기에 광배근을 추가하고, 승인된 뒤돌아보기 시안의 몸통 관계를 새 입체 비틀기 도해로 구성한다.

- `flexion.js`: 기존 상체 골격을 사용하는 정면·측면 말기, 골반 고정, 팔뼈 생략. 광배근은 복벽 뒤와 옆구리에 놓는다.
- `twist.js`: 3D 좌표의 척추·흉곽·견갑대, 몸통에 감긴 다섯 근육과 섬유. 양쪽 광배근은 각각 연결된 부채꼴이다. 도해의 회전 축과 카메라를 공유한다.
- `depth-renderer.js`: WebGL의 깊이 검사와 고정된 16° 정사영. 중립 좌표를 한 번 업로드하고 회전은 셰이더에서 계산한다. 별도의 근육 ID 버퍼에서 보이는 이름표 도착점을 찾는다. UI와 고정 골반은 기존 SVG를 유지한다.
- `controls.js`: 말기/비틀기 값의 분리, 재생·정지, 세 버튼, 모바일 맞춤, 통합 상태 저장과 이전 `abdomen-spine-curl-v1` 저장값 이관.
- `build.py`: 외부 자산 의존성이 없는 HTML 생성. `--publish`는 독립 페이지와 통합본의 복부 문서만 갱신한다.
- `review.py`: 실제 브라우저 렌더링·기하·표시·저장값·샌드박스·터치 검사.

저장소 루트에서 `python work/abdomen/build.py --publish`로 생성한다. 저장소 루트를 제공하는 로컬 서버를 실행하고 `python work/abdomen/review.py`로 검사한다. 기본 주소는 `http://127.0.0.1:8767/`, `ANATOMY_REVIEW_BASE`로 변경 가능하다.

최대 비틀기 −140°/+140°와 허리 구간의 회전 분포는 큰 뒤돌아보기 형태를 위한 **작화용 도해**다. 실제 척추 관절의 정상 가동범위·접촉·변형·근섬유 수축률을 계산하지 않는다. 기본 새 사용자 자세는 +135°·일시정지다. 기존 저장된 말기 자세는 유지한다.

색상과 미세한 섬유, 층의 관계는 기존 상체·복부와 같은 OpenStax A&P 2e 11.4/11.5 검토 기준을 사용한다. 해부학 검토의 판단 범위와 한계는 저장소의 `ANATOMY_REVIEW.md`에 기록한다.
