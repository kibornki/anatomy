# 부위별 근육 크기와 지방량

각 부위 탭에 근육 크기 60–160% 조절을 제공한다. 100%는 원래 아틀라스다.
지방은 0–100의 도해용 양으로 조절하고 노란 덩어리로 그린다.
지방 반투명과 기존 근육 반투명을 별도로 조절하며 체형 초기화를 제공한다.

상체의 가슴과 옆구리, 복부의 아래쪽 배와 옆구리, 상완 뒤쪽, 허벅지
위쪽 바깥·안쪽에 지방 덩어리를 추가한다. 전완에는 지방 덩어리를
추가하지 않는다. 부위별 값은 기존 상태 저장과 통합본 메시지에 포함한다.
복부 단독 페이지에도 상태 저장을 추가한다.

근육 단면을 조절하되 뼈·관절과 명시된 기시·정지 정점은 유지한다.
기존 원본의 뼈 접촉 정점도 보호한다. 근섬유와 건막은 변경한 표면을
따르고 지방 덩어리는 인접 조직의 운동을 따른다. 기본값은 기존 그림을
유지한다. 원본 아틀라스와 운동 데이터는 수정하지 않는다.

크기 퍼센트는 외형 기준이며 실제 근육량, 힘, 생리적 비대나 지방률의
실측값이 아니다. 지방 위치·형상은 일반적인 분포를 나타내는 작화용
근사이며 성별·개인별 분포나 실제 조직층을 재현하지 않는다. 큰 크기에서
근육끼리의 새로운 접촉은 실측이나 전체 삼각형 충돌 검사로 인증하지 않았다.

생성:
- python work/upperbody/build.py
- python work/arm/build.py --publish
- python work/abdomen/build.py --publish
- python work/limb/build.py --publish

검증:
- node work/composition/review-geometry.cjs
- 로컬 서버 8767과 Playwright 설치 후 node work/composition/review-browser.cjs

GitHub Actions는 다섯 단독 페이지와 통합본을 만들고 geometry 및 브라우저
검사를 실행한다. 모든 검사가 통과한 생성 HTML은 기능 브랜치에 기록한다.
생성본과 모바일 캡처는 anatomy-body-composition 아티팩트에
보관하며 자동으로 게시하지 않는다.
