# 실사비교 생성 이미지 검수

검수·수정일: 2026-10-12. 현재 실사비교 배포 대상은 수정한 스케치 9장이다. 기존 생성 실패 6장과 이번 수정 생성이 차단된 `상체 · 정면` 1장을 목록에서 제외했다. 실패 자료의 임시 SVG도 배포하지 않는다.

사진과 스케치를 육안으로 비교하고 아래 교재의 표면 근육 배치와 대조했다. 아래의 최초 검수 내용을 바탕으로 built-in `image_gen`으로 근육 그림을 재생성했다. 프롬프트와 채택 결과는 `corrections.json`에 기록했다. 사진 원본은 유지했다.

## 이번 수정과 재검토

| 대상 | 반영한 수정 |
| --- | --- |
| 허벅지 정면 2장 | 중앙 대퇴직근의 반복된 사선 근복을 긴 주 근복으로 정리했다. 외측광근과 내측광근의 영역을 구별하고 무릎 위 힘줄 연결을 정리했다. 가까이 사진의 양쪽에 중복 생성된 내측광근을 추가 수정했다. |
| 레그프레스 | 원본을 다시 확인했다. **이전 검수에서 하퇴로 해석한 왼쪽 영역도 실제로는 허벅지이며 하퇴는 화면 밖이다.** 수정 중간본에서 생긴 중앙 무릎 2개를 폐기하고 실제 왼쪽 끝의 무릎 2개만 남겼다. 중앙부터 왼쪽까지 연속된 대퇴사두근으로 다시 그렸다. 원본 윤곽과 크게 어긋난 중간본도 폐기하고 세 번째 수정 결과를 사용한다. |
| 등 3장 | 광배근 아래쪽에 흉요근막 영역을 구분했다. 견갑부의 근복과 삼두근·전완의 힘줄 경계를 정리했다. 승모근·극하근·대원근·광배근의 표면 영역을 재확인했다. |
| 정면 매달리기 | 전거근은 파란 늑골 톱니, 외복사근은 그 아래의 초록 복벽으로 구분했다. 대흉근 상부 방향과 복직근의 건획 경계를 정리하고 외복사근 명칭을 추가했다. |
| 이두근 사진 | 아래쪽 파란 덩어리를 줄여 상완근의 노출과 구별하고 뒤쪽 삼두근을 보라색의 이어진 영역으로 정리했다. 이두근 원위 건과 전완의 건 경계를 보완했다. |
| 삼두근 사진 | 공통 삼두근 건막과 팔꿈치로 향하는 힘줄을 보완했다. 전완은 원위부로 가늘어지는 근복·건으로 정리했다. |
| 상체 정면 | 수정 생성이 출력 단계에서 거절되어 배포에서 제외했다. 기존 오류 그림을 그대로 게시하지 않았다. |

재검토는 큰 표면 근육의 식별, 주요 건·근막의 구분, 원본 자세와 비교할 수 있는 배치에 한정한다. 생성 그림의 근섬유 수·모든 근두·부착점을 실측 수준으로 검증한 것은 아니다. 깊은 구조와 불분명한 전완 세부 근육은 개별 이름을 붙이지 않았다. 근육만 수정하는 생성에서도 사진과 경계가 조금 달라질 수 있으며 픽셀 단위 정합을 보장하지 않는다.

| 허벅지 · 가까이 | 대퇴사두근, 외측광근, 내측광근 | 바깥쪽 파란 덩어리와 안쪽 무릎 위 초록 덩어리는 위치상 광근으로 식별 가능하다. 중앙의 빨간 덩어리는 여러 사선 조각으로 갈라져 대퇴직근 하나로 확정하기 어렵다. 중앙에는 상위 근육군인 대퇴사두근만 표시했다. 무릎 아래 연결과 봉공근의 경로도 부정확하다. |
| 허벅지 · 레그프레스 | 대퇴사두근 | 허벅지 앞쪽이라는 영역만 식별 가능하다. 굽힌 무릎 주변에서 근복과 건이 장식적인 띠처럼 이어지고 광근·대퇴직근의 경계가 불명확하다. 개별 광근과 하퇴 근육의 이름을 억지로 붙이지 않았다. 이 그림은 세부 해부학 학습용으로 재작화가 필요하다. |

## 명칭 표시 방식

- `muscle-labels.json`은 원본 이미지의 백분율 좌표를 사용한다. 색만으로 근육을 지정하지 않는다. 사진마다 색 체계가 다르다.
- 명칭과 연결선은 별도의 SVG 텍스트 레이어이며 원본 래스터에 이름을 합성하지 않았다.
- 슬라이더가 스케치를 드러낼 때만 표시한다. 명칭 상자와 근육을 가리키는 점이 모두 스케치 영역에 들어온 경우에만 해당 명칭을 온전히 보여준다.
- 연결선은 명칭 상자 경계에서 끝난다. 글자 위를 지나가지 않는다.
- 같은 좌우 근육은 한쪽에 대표 명칭을 표시한다. 중복 이름으로 그림을 덮지 않는다.
