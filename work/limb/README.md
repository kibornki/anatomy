# 전완·허벅지 원본 아틀라스 적용

`work/limb-atlas-preview/atlas-data.json`의 승인된 실제 뼈·근육 표면을
단독 페이지와 통합본에 적용한다. 색은 `../limb-atlas-preview/colors.json`에
있는 근육군 색(전완)과 근육별 색(허벅지)이다.
허벅지 대퇴이두근 장두·단두는 하나의 보라색과 명칭으로 묶으며
기하 형상과 동작은 유지한다. 다른 허벅지 근육은 기존 구분을 유지한다.
전완은 굽힘근군·폄근군·회내근군을 묶고 상완요골근·회외근을 구분한다.
같은 근육의 두 기시부도 같은 색과 하나의 명칭으로 표시한다.
힘줄의 흰 면과 상완 연결부 문맥은 이 색 범례에 포함하지 않는다.

기존 페이지의 기본 스타일·버튼·슬라이더 ID와 조작 순서를 템플릿으로
보존한다. 정면·측면·후면, 재생, 근섬유·반투명, 통합본 상태 복원을 유지한다.
허벅지의 정면 32°·후면 148° 사선과 무릎 아래 짧은 골격도 유지한다.
정강이뼈·종아리뼈는 원본 절단 범위를 무릎 아래 72 mm에서 96 mm로
24 mm 넓혔다. 뼈를 늘이거나 기존 근육 형상을 바꾸지 않는다.
기존 바깥쪽 측면 90° 옆에 측면(반대) 270°를 추가해 내전근과
내측광근을 안쪽에서 본다. 새 시점도 재생·반투명·상태 저장을 공유한다.
골격·근육 선택·정적 자료 출처·라이선스는 아틀라스 시안 README를 따른다.

## 움직임과 한계

전완의 요골·손 골격은 원본 요골두와 척골 원위부를 잇는 축 주변에서
강체 회전한다. 척골·상완골은 고정한다. 부위별 종방향 회전으로 근육을
따라가게 하며, 방형회내근은 고정 척골과 회전 요골 사이의 표면을 연결한다.
정확한 회내·회외 기시·정지부 접촉, 근섬유 수축, 활성도는 검증한 모델이 아니다.

허벅지의 대퇴골·골반은 고정하고 잘린 경골·비골은 무릎에서 강체 회전한다.
슬개골의 이동은 기존 도해의 0.7 회전 비율을 사용하는 근사다.
기존 페이지가 사용한 OpenSim 4.6 Gait2392 근육·힘줄 경로 표를
`motion-reference.json`에 보존한다. 길이 표는 실제 근복 길이·근활성도가 아니다.
근복과 원위 힘줄의 변형을 분리한다. 햄스트링은 굽힘에서 짧고 두꺼워지고,
사두근은 길고 얇아진다. 사두근 근복은 슬개골 쪽 여유를 넘지 않도록 제한한다.
단면 배율 `1/신장`, 반경 배율 `1/sqrt(신장)`은 작화 가이드이며
모든 변형 조직의 전체 부피를 보존한다고 주장하지 않는다.

기존 팔의 실제 원본 뼈 폐곡면 voxel SDF 생성 코드를 재사용한다.
격자는 2mm, 보정 이동 한도는 10mm다. 요골·슬개골·경골·비골은 각각의
중립 좌표로 역변환해 검사한다. 이 격자와 표면 축소의 한계가 있으므로
전 조직·전 화면 픽셀의 정확한 접촉을 인증한 검사가 아니다.
근육 표면과 가림은 복부의 `AbdominalVisibility`/`AtlasContour`를 공유한다.
근섬유는 표면 작화 가이드이며 측정된 섬유 방향이 아니다.

## 재생성

```sh
python work/limb/bone-fields.py
python work/limb/build.py
python work/limb/build.py --publish
# 허벅지만 갱신할 때
python work/limb/build.py --thigh-only --publish
```

첫 빌드는 `/workspace/artifacts/limb-implementation`에 검토용 페이지를 만든다.
`--publish`는 전완·허벅지 단독 페이지와 index.html의 두 항목만 갱신한다.
`node work/limb/review-geometry.cjs`로 골격 거리·역변환을 전완 161각도,
허벅지 121각도에서 검사한다. 중립 자세의 첫 1°에서 원본 면이 갑자기
뛰지 않는지 원본 전체 정점도 검사한다.
접촉 표면은 일부 각도·정점을 샘플링했고, 브라우저의 양 끝·중간 자세,
세 시점, 반투명·근섬유·재생, 390/320px 모바일과 통합본 상태 복원도 검사했다.
결과는 `geometry-validation.json`, `ui-validation.json`에 기록한다.
