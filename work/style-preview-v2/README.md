# 상체·전완·허벅지의 복부 표현 스타일 시안

현재 앱에서 같은 자세를 렌더링하고, 시안에만 재질 표현을 적용한다.
상체 60° 팔 외전, 전완 중립 0°, 허벅지 무릎 폄 0°.
각 부위의 기존 정면·측면·후면과 원래 색 분류를 유지한다.

- 복부처럼 불투명한 색면, 회색 골격, 흰 기존 힘줄·근막을 사용한다.
- 기존 곡면 섬유 가이드 사이를 보간하고 동일한 근육 클립 안에 표시한다.
- 뼈의 겹친 단면을 모두 선으로 표시하지 않고 기존 채움의 바깥 윤곽을 추출한다.
  윤곽 추출은 복부의 `AtlasContour`를 공유한다.
- 기존 path 좌표·transform을 변경하지 않았는지 아홉 시점에서 검사한다.
  카메라 값과 검사 결과는 `validation.json`에 저장한다.

이는 표현 스타일 시안이다. 기존 상체·전완·허벅지의 수작업 해부학 근사를
새 아틀라스로 교체하거나 측정된 섬유 궤적으로 검증했다고 주장하지 않는다.
새 근육·건막 면·부착점·근육 덩어리를 만들지 않는다.

`python -m http.server 8767 --bind 127.0.0.1` 실행 후
`python work/style-preview-v2/render.py`로 세 부위를 한 프로세스에서 생성한다.
부위별 원본 페이지는 한 번만 불러와 그 안에서 시점을 전환한다.
생성 PNG는 `drafts/abdomen-style-review-v2`, 검토용 정적 HTML은
`/workspace/artifacts/style-preview-v2`에 저장한다.
원래 앱 페이지와 통합본은 수정하지 않는다.
