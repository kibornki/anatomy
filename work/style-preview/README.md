# 표현만 바꾼 시안

현재 상체·허벅지·전완 SVG를 렌더링한 뒤 윤곽과 시점을 유지하고,
그라데이션·선 두께·근섬유 선만 변경한다. 새 근육이나 힘줄 면을 생성하지 않는다.
모든 path의 d와 transform이 변경 전후 같은지 확인한다. 허벅지는
승인된 무릎 아래 표시 범위 변경이 먼저 반영된 원본을 사용한다.
기존 상체·허벅지·전완의 해부학 근사를 아틀라스 모델로 교체한 시안이 아니다.

로컬 서버를 8767에서 실행한 뒤 `python work/style-preview/render.py`로 재생성한다.
실제 앱의 스타일에는 반영하지 않았으며 `drafts/style-only-review`에서 시안만 제공한다.
