# 상체: 원본 표면과 부착 영역을 사용한 3D 도해

## 광배근 근복·건막 및 섬유 흐름

사용자가 승인한 후면 시안에 따라 허리 중앙의 흉요근막/건막 영역과
상완 쪽으로 감기는 건 이행부를 연한 색으로 구분한다. 기존 광배근의
삼각형을 재료 경계에서 나누며, 추가 표면을 겹쳐 붙이거나 원본 뼈,
근육의 중립 정점 및 뼈 운동을 변경하지 않는다. 상부·중부·하부 경로는
중앙의 여러 높이에서 출발한다. 중앙 건막을 지나 드러나는 근복은
먼저 바깥쪽으로 펼쳐진 후 겨드랑이 이행부를 돌아 상완 쪽으로 흐른다.
43개 주요 경로는 중립 좌표의 |x|=0.8, y=244–389에서 시작하고,
끝점은 기존 아틀라스의 상완 부착 정점에서 선택한다. 하부 경계
표면을 경로 시작점으로 반복하거나 근복을 부착점까지 직선으로
끌어올리던 이전 표현을 사용하지 않는다. 중앙 경로의 건막 구간과
근복 구간은 재료 경계에서 나누고, 가려진 선을 승모근 위로 그리지 않는다.
모든 선을 아래쪽 한 점이나 노출된 상완의 한 점으로 몰지 않는다.

겨드랑이 경유점은 견갑골 하각 아래가 아니라 원본 광배근 외측 이행부
(x=92.5–94, y=236–239)를 통과한다. 건 이행부는 y<219, |x|>94의
상완 부착점 근처로 제한하여 겨드랑이 근복이 흰 영역으로 끊기지 않게 한다.
거상 시 광배근의 근복은 흉곽을 감싸며 겨드랑이 뒤주름으로 이어지고,
상완 가까운 건은 대원근 앞쪽으로 돌아 원래 상완 부착 영역에 도달한다.
측면에서는 전거근의 뒤쪽·아래쪽 일부를 광배근이 바깥에서 덮고,
전거근 앞쪽은 드러난다. 내측 광배근은 승모근 하부보다 깊다.
정상적인 표층 겹침을 없애려고 광배근 전체를 뒤로 밀지 않는다.

`axillary-fit.py`는 다음 단계를 실행한다. 이전 자세를 다음 자세의 실제
상완 부착 변화로 옮기는 조화 변형, 자유 근복의 겨드랑이 경로 맞춤,
측면 외피의 전거근 바깥 감싸기, 마지막 세밀한 면 거리 보정이다.
원본 기시·정지 정점, 중립 표면, 다른 근육과 뼈는 유지하고, 자유 근복의
두께로 원래 폐곡면 부피를 보존한다. `latissimusMotionSeed`는 재생성의
동일한 시작 자세를 기록한다. 거리장 캐시는 입력 형상과 자세별로 구분한다.
이 경로와 간격은 도해용 제약이며 실측한 조직 운동 데이터가 아니다.

각 가이드 점과 재료 경계는 원본 삼각형의 barycentric 좌표에 붙인다.
런타임에서 실제로 변형된 동일 삼각형을 따라 움직이며, 근육과 건막을
같은 깊이 버퍼에서 처리한다. 반투명도는 조직별 중복 표면 없이 한 번
적용한다. 가이드는 근복/건막별 색과 clip을 사용한다.

Gray 후면 도판, MoBL ARMS 경로 사본 및 승인 시안의 지역별 방향과
조직 구분을 참고한 **도해용 경계**이다. BodyParts3D에서 해당 근복/
건막 경계를 실측하거나 섬유를 추적한 것이 아니다. 열람한 자료와
기존 오류는 LATISSIMUS-REVIEW.md에 기록했다. 경계 좌표, 경유점과
섬유 경로를 특정 개인의 조직 분할이나 생리적 수축으로 해석하지 않는다.

표현만 재생성할 때 기존 변위 프레임을 재사용한다:

```sh
python work/upperbody/axillary-fit.py
python work/upperbody/latissimus-detail.py
python work/upperbody/build.py
python work/upperbody/review-latissimus.py
```

`prepare.py` 전체 실행 후에도 이 작성 과정을 자동으로 적용한다.
review-latissimus.py는 재료 분할 면적, 삼각형 좌표, 원본 표면/운동/
다른 부위 유지 여부와 중앙 경로의 시작점 및 상완 부착 영역 선택을
검사한다. 각 섬유가 분리된 원본 표면 성분 사이를 뛰어넘지 않는지도 검사한다.
이는 해부학적 근섬유 실측 검사가 아니다.

모바일에서도 지역별 흐름을 읽을 수 있도록 같은 카메라에서 상체
표시 배율을 키웠다. 좌우 프레임을 넘어가는 상완 뼈는 표시 경계에서
잘라 보이지만, 원본 골격 정점이나 실제 운동 데이터는 변경하지 않는다.

BodyParts3D의 중립 뼈·근육 표면, 기존 11개 근육, 색, 세 시점과 조작 UI를
유지한다. 머리·복부 근육·삼각근을 추가하지 않는다. 원본 축과 균일 배율을
유지하며 흉곽 너비나 근육 자체의 중립 형상을 임의로 조절하지 않는다.

## 최대 거상 변형 수정

기존 최근접 뼈의 역4승 가중치가 좁은 구간에 신장을 집중시켜 승모근
하부와 대흉근의 상완부 이행부를 과도하게 펼쳤다. 그 변형을 교체한다.

- 원본 뼈와의 인접 관계 및 근육의 해부학적 끝 부분을 사용해 기시·정지
  영역을 따로 정한다. 광배근의 척추·장골·늑골 기시, 승모근의 목/척추 기시,
  대흉근의 쇄골/흉늑/하부 기시를 각각 고정하거나 해당 뼈에 붙인다.
- 기시와 정지를 고정한 국소 회전 기반 3D 표면 맞춤을 사용한다. 근복을
  최근접 뼈에 통째로 붙이지 않는다. 원본 폐곡면 부피를 유지하는 보정은
  자유 표면의 두께를 조절하며 부착 정점을 이동하거나 전체를 축소하지 않는다.
- 상완골의 장축 회전과 견갑의 입체 방향 변화, 쇄골 후퇴를 별도로 다룬다.
  견갑/상완 관절 중심은 함께 이동하고 뼈는 강체를 유지한다.
- 실제 원본 뼈의 1.25 단위 signed distance grid로 자유 표면의 추가 관통을
  보정한다. 광배근의 넓은 후면 표면은 흉곽의 뒤쪽 외피를 따른다. 뼈를
  완전히 지나 내부로 이동한 경우를 거리 값만으로 놓치지 않도록 한다.
- 수정한 5° 간격 표면을 보간하고 원본 섬유 가이드도 함께 이동한다.
  0.02 단위 정밀도의 변위로 저장한다. 목 절단은 상부 승모근에만 적용한다.
  팔을 높이 올리면 SVG 영역을 확장해 팔뼈가 잘리지 않게 한다.

부착 영역은 원본 표면의 인접 관계와 도해용 해부학적 영역 설정이다. 이
자료는 실측한 근육/건 분할이나 근섬유 추적 데이터를 포함하지 않는다.
쇄골 상승 angle/6·후퇴 최대 6°, 견갑 상방회전 angle/3·후방경사 최대 10°·
수직축 회전 최대 8°, 상완 장축 회전 최대 35°는 도해용 결합 값이다.
특정 인체의 실제 운동 범위, 활성도, 생리적 근육 부피를 검증한 모델이 아니다.

참고한 관절 구조: OpenSim 공식 ScapulothoracicJointPlugin,
고정 커밋 ad2a40c0fdb242eb8de9b61c56aae9418303225b의 ScapulothoracicJoint.h.
흉곽 표면과 견갑 위치/상방회전/winging을 구분하는 구조를 참고했다.
해당 구현 전체를 이 앱에 이식했거나 도해 각도를 임상 데이터로 얻었다는
의미는 아니다. 시안의 좌표 복제는 수정 후의 동적 형태 평가를 대신하지 않는다.

## 재생성 및 검토

```sh
python work/upperbody/prepare.py
python work/upperbody/build.py
node work/upperbody/review-geometry.cjs
python work/upperbody/review-latissimus.py
python work/upperbody/review-contact.py
python work/upperbody/review-tissue-contact.py
```

기존 neutral atlas-data.json을 입력으로 사용한다. 중립 표면은 유지하고
변위 프레임만 다시 만든다. 새 환경에서 중립 데이터가 없으면
../upperbody-atlas-preview/prepare.py로 pinned 원본 STL을 준비한다.
뼈 거리장 캐시는 /workspace/artifacts/upperbody-motion-audit에 둔다.
NumPy/SciPy와 기존 Chromium/Playwright 환경을 재사용한다.

106개 각도에서 부착 오차, 원본 폐곡면 부피 오차, 뼈 강체 거리와 프레임
연속성을 검사한다. 정면/측면/후면과 양 끝/중간 자세를 실제 렌더로 비교하고,
재생·반투명·근섬유·모바일·통합본 상태 복원을 확인한다. 그리드와 표면
축소에는 오차가 있으므로 모든 조직 접촉을 인증하는 검사는 아니다.
결과는 geometry-validation.json, motion-validation.json, ui-validation.json에 둔다.

복부·팔과 같은 AbdominalVisibility/AtlasContour를 사용한다. 반투명은
근육 전체에 0.3을 적용하고 뼈와 근육의 가림을 별도로 계산한다.

자료: BodyParts3D © 2008 DBCLS, CC BY-SA 2.1 Japan.
STL 변환: Kevin Mattheus Moerman. 출처·캐시·원본 라이선스는
../upperbody-atlas-preview/README.md 및 LICENSE-BodyParts3D.txt에 있다.
앱에도 출처와 라이선스 링크를 표시한다.

`review-contact.py`는 각 삼각형의 55개 점에서 원래 견갑골과 떨어져 있던
광배근 면을 검사한다. 15–120°의 106개 보간 각도에서 기존 견갑골 거리장을
사용한다. 원래의 접촉/겹침은 제외하며, 그리드 근사에 대한 회귀 검사다.
`face-clearance-validation.json`은 저장된 22개 자세에서 전거근·대원근·
승모근 하부와 뼈에 대한 자유 면 검사 결과다. 고정 부착점만으로 이루어진
샘플은 움직이지 않으므로 보정 대상에서 제외한다. 검사는 모든 접촉의
정확한 삼각형 교차 인증이나 생리적 운동 검증을 의미하지 않는다.

`review-tissue-contact.py`는 저장 자세와 그 사이 2.5° 자세의 총 43개에서
실제로 저장·보간한 면을 전거근·대원근·승모근 하부 거리장과 비교한다.
원본 접촉과 고정 부착점 전용 샘플은 제외하며 −0.25 단위 미만의
새 관통을 검출한다. 결과는 tissue-contact-validation.json에 저장한다.

## 사진을 참고한 상체 체형 시험

상체 아래의 ‘상체 체형 맞추기 · 시험’을 펼친다. 너비·흉곽 깊이·몸통
길이를 95–105% 범위에서 조절하고 기존 세 시점과 팔 외전 동작을 사용한다.
사진에서 사람을 자동 검출하지 않는다. 사용자가 쇄골 사이/골반 윗선과
흉곽 양끝의 네 기준점을 찍으면 몸통 길이에 대한 폭 비율을 계산한다.
정면은 너비, 측면은 깊이를 맞춘다. 범위를 넘으면 제한 사실을 표시한다.
겉비율에는 지방·옷·원근이 포함되므로 표준 내부 구조에 적용하는 참고치다.
사진의 근육량, 피부, 개인의 부착점을 복원하는 기능은 포함하지 않는다.

사진은 FileReader로 메모리에서 읽으며 네트워크나 localStorage에 보내지
않는다. 사진 지우기는 이미지와 기준점을 제거한다. 체형 숫자만 기존
통합본 상태에 저장해 다른 부위로 전환한 뒤에도 복원한다.

형상은 동일한 중립 골격을 한 번 재비례화한 뒤 기존 관절 회전으로 움직인다.
애니메이션 도중 뼈 길이를 바꾸지 않는다. 근육은 기존의 검토된 동작에
기시·정지의 비율 변화에서 유도한 조화 보정을 적용한다. 자유 근복의
폐곡면 부피를 유지하고 광배근에는 견갑골 거리장과 체형 끝값에서 맞춘
작은 접촉 보정을 적용한다. 원래 체형에서는 기존 표면을 그대로 반환한다.
보정은 표준 도해의 비율 시험이며 특정 인물의 해부학이나 움직임 실측이 아니다.

원본 atlas가 바뀌면 아래 순서로 재생성한다. 첫 geometry 실행은 기본
체형의 접촉 보정을 맞추기 위한 임시 자세 파일도 출력한다.

```sh
python work/upperbody/prepare-body-fit.py
node work/upperbody/review-body-fit.cjs
python work/upperbody/fit-body-contacts.py
node work/upperbody/review-body-fit.cjs
python work/upperbody/review-body-fit-contact.py
python work/upperbody/build.py
python work/upperbody/review-body-fit-ui.py
```

상체 source fingerprint가 일치하지 않으면 build가 중단된다. geometry 검사는
기준/끝값 조합 9개 체형의 106개 각도에서 뼈 거리·부착·근복 부피·연속성을
확인한다. 접촉 검사는 15/60/90/120°에서 각 면의 55개 점을 사용해
원래 떨어져 있던 광배근 자유 면을 주변 뼈·전거근·대원근·승모근 하부와
비교한다. 원본 접촉/고정 부착점 전용 샘플은 제외하고 −0.25 단위 미만을
관통으로 본다. 이는 모든 중간 체형과 각도의 정확한 삼각형 교차 인증이나
개인의 해부학 검증을 대신하지 않는다. 모바일·사진 기준점·상태 복원도
실제 브라우저에서 확인하며 결과는 body-fit-*-validation.json에 기록한다.
